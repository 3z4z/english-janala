## Overview

**ENGLISH JANALA** is a simple, clean, and interactive English learning platform designed using modern UI tools.  
The goal is to make learning English easy, fun, and accessible for everyone.
- You can browse words and see bangla pronounces
- You can also see the bangla meaning of any word
- There is a dynamic search option to find your desired word
- The lesson based learning will bring your english skill to a next level 


## Technologies Used

- **HTML5**
- **CSS3**
- **TailwindCSS**
- **DaisyUI**
- **Netlify** (for deployment)
